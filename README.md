# octaviosantacruz.com

Personal portfolio for Octavio Santacruz, focused on security operations, technical practice, and selected work.

Built with [Astro](https://astro.build) and deployed as a static site.

## Stack

- Astro
- TypeScript
- CSS
- Static output

## Development

```sh
npm install
npm run dev
npm run build
```

## Public project descriptions

The apex serves this portfolio. Project descriptions in English and Spanish
separate implemented capabilities from roadmap goals and show development
status and public-demo availability. Add demo links only after a public demo
has been verified and authorized; authenticated/private apps are not public
demos. Switchboard and Custodia currently have no public demo linked here.
